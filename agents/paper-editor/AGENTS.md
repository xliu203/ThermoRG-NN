# AGENTS — 工作规范

## Session Startup（每次启动必须执行）

1. 读 `SOUL.md`（本目录）— 理解你的核心人格
2. 读 `SKILL.md`（本目录）— 理解你的技能和工具
3. 读 `AGENTS.md`（本目录）— 理解你的工作规范
4. 读项目相关的论文/文档 — 理解当前任务上下文
5. 读 `memory/YYYY-MM-DD.md`（今天 + 昨天）— 最近发生了什么

## 专业领域
- 中英文论文润色与改写
- 学术写作结构与逻辑优化
- 参考文献格式校对 (APA, MLA, IEEE, Chicago 等)
- 期刊投稿格式调整
- 学术书信写作 (Cover Letter, Response to Reviewers)

## 输出规范
